# LOL 国服中文启动助手

在海外正式服客户端中使用大陆简体中文资源（`zh_CN`），保留原来的账号和服务器。

本项目用于解决 Riot 启动器将语言配置自动重置的问题：启动时修改语言，并在 Riot 运行期间检查配置，必要时重新设置 `settings.locale`。不修改游戏程序、系统权限或反作弊组件，不需要管理员权限，不添加开机启动。

> 这是社区脚本，不是 Riot 官方工具。已在一台 Windows 美服正式服电脑上验证核心方案：下载中文资源后，大厅显示“云顶之弈”“冠军杯赛”等大陆中文，重启后仍以 `zh_CN` 运行。配音资源已下载，但未通过对局试听验证。未来客户端更新可能使此方法失效。

## 快速开始

1. 在本仓库点击 **Code → Download ZIP**，将压缩包完整解压到一个你有写入权限的文件夹。
2. 先退出 LOL 和右下角托盘中的 Riot Client，避免当前客户端覆盖初始设置。对局结束后再操作。
3. 双击 **`Start.cmd`**。
4. 在打开的 Riot 客户端点击“游玩”。如果需要下载语言资源，等待下载结束。
5. 保留脚本窗口，可以最小化；进入 LOL 大厅检查游戏语言。

以后也通过 `Start.cmd` 启动。只使用原来的 Riot 快捷方式，语言可能被重置。美服活动网页、新闻和个别按钮仍可能是英文；Riot 启动器自身的语言也不会由本脚本修改。

文件名采用英文以便命令行兼容；说明、运行提示和测试提示均为中文。需要 Windows 10/11 和 Windows PowerShell 5.1；不支持 macOS、国服 WeGame 或 PBE。

## 三个入口

| 文件 | 用途 |
| --- | --- |
| `Start.cmd` | 启动 Riot 并维护大陆中文语言设置 |
| `Stop.cmd` | 请求停止从同一文件夹启动的维护程序，不关闭游戏 |
| `Check.cmd` | 检查路径和配置格式，不修改游戏文件 |

按 `Ctrl+C` 也可结束维护。Riot 完全退出后，程序通常会在约 15～20 秒后结束；启动初期有约 30 秒的等待窗口。

## 自动查找与手动路径

默认从系统 `ProgramData` 中寻找游戏配置，并通过 Riot 自己的 `RiotClientInstalls.json` 寻找启动器。因此游戏安装在其他盘符通常不需要额外设置。

自动识别失败时，将 `config.example.json` 复制为 `config.json`，填写真实路径：

```json
{
  "configPath": "C:/ProgramData/Riot Games/Metadata/league_of_legends.live/league_of_legends.live.product_settings.yaml",
  "riotClientPath": "D:/Riot Games/Riot Client/RiotClientServices.exe"
}
```

上面的 D 盘只是示例。JSON 路径可用 `/`，如使用反斜杠需写成 `\\`。保留空字符串表示自动识别。不要分享包含本机路径的 `config.json`。

## 备份、停止和恢复

首次需要改写配置时，会将原文件逐字节备份到项目内 `.runtime/backups/`。备份按完整配置路径区分，不会在每次重置时覆盖最初备份。

若想恢复其他语言：

1. 运行 `Stop.cmd` 并等待原来的脚本窗口结束。
2. 完全退出 LOL 和 Riot，再用原来的 Riot 快捷方式启动。
3. 在 Riot 设置中选择原来的游戏语言，等待资源更新。

需要手动恢复备份时，先完成前两步中的退出操作，再将对应的 `.original.yaml` 复制回原配置路径。不要在更新或游戏运行过程中覆盖配置。项目没有后台服务；停止程序后可以删除解压文件夹。

## 常见问题

**窗口一闪而过，或提示无法运行脚本？**

通过 `Start.cmd` 而不是直接双击 `.ps1` 启动，失败时窗口会保留错误。如果 Windows 标记下载文件来自互联网，可检查文件属性中的来源提示。脚本不会自动更改执行策略；由单位管理且禁止脚本执行的电脑应遵守本机策略。

**提示拒绝访问、文件只读？**

如果之前按其他教程设置过“只读”或“拒绝写入”，先恢复这些限制。本项目需要能正常写入这一份配置文件，不会修改权限，也不需要锁住整个文件夹。

**仍然是台湾中文，或启动后又恢复？**

检查是否通过 `Start.cmd` 启动、维护窗口是否还开着，以及是否显示错误。关闭游戏和 Riot 后重新尝试。不要同时运行多个语言修改工具。连续约 30 秒无法维护配置时，程序会报告错误并停止，不会假装成功。

**为什么下载了几 GB，或者更新后又要下载？**

语言切换可能触发中文资源下载；当前版本首次实测约 3.3 GB，实际大小由 Riot 决定。客户端更新或语言回退后可能再次下载。

**运行后会转到国服吗？**

不会。脚本只改语言字段，不改服务器、账号、商店或活动归属。不承诺官方支持或任何账号处理结果。

## 实现范围

- 每 250 毫秒检查语言字段；正确时不写入。
- 仅修改根级 `settings` 下的直接 `locale` 字段，保留其他设置、注释、换行和 UTF-8 BOM 状态。
- 配置缺失、字段重复或格式不符合预期时拒绝猜测修改。
- 自动备份首次原始内容；同一登录会话只运行一份本项目维护程序。
- 游戏资源由 Riot 客户端下载；脚本自身不发送账号信息、遥测或网络请求。
- 不终止任何游戏进程，不注入游戏，不提供游戏内自动操作。

## 开发与验证

无需安装额外依赖。在项目目录运行：

```powershell
powershell -NoProfile -File tests/Run.Tests.ps1
powershell -NoProfile -File Start.ps1 -Check
```

自动测试覆盖修改范围、嵌套字段、重复字段拒绝、换行、引号、原始备份和编码保留。它们使用临时测试文件，不会修改真实 LOL 配置。GitHub Actions 在 Windows PowerShell 5.1 和 PowerShell 7 中运行测试。

本仓库附带的通用版本进行了测试和本机只读路径检查；此前的精简版本完成了真实客户端重启验证。不能将单机结果理解为所有地区、版本均已验证。
